# Product design

Read [the design entry point](../../../assets/design-system/README.md), then shared guidance and only the selected product guide. The entry point resolves local light-background direction, source caveats and known typography/color exceptions. Resolve product and output format before selecting rules; do not infer indication or CRM routing from design copy.

Use local image-library instructions for imagery and hosted links. Treat KOL photos as candidates until verified and claim evidence status as distinct from marketing approval. Read the linked page/form or email implementation procedure for the actual medium. Keep output external to Git and inspect the rendered result before delivery.
