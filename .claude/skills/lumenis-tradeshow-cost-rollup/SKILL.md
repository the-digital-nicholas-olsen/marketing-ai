# Tradeshow cost rollup

Owner: Kaelyn.
Status: draft procedure, written 2026-11-03 from the Vision tradeshow planning session; not yet run. Review required.

## Procedure

1. Collect every cost from the show's rows and the project folder:

| Line | Row |
|---|---|
| Registration | R5 |
| Sponsorships | R8 |
| Booth build | B5 |
| Show services (Brex) | B5 |
| Print (Mimeo) | F4 |
| Dinner venue, food, decor | N3, N8, N9 |
| KOL honoraria | K3 |
| Shipping, supplies | F4, F7 |

2. Mark each line Invoiced or Estimated. An estimate needs a note saying what's outstanding.
3. Total the show and the dinner separately, then together. Write them to P11 Key Info.
4. Draft an email to EJ (who enters the total in the Salesforce campaign, P12) and Derek (who reconciles budget vs actuals once every invoice is in, P13).

## Boundaries

- Drafts only. Amounts come from purchase requests and invoices, never from memory.
- Cost detail stays in the work systems, not in this repository.
