The Lumenis line-illustration set — clean, essential strokes that convey "tech and beauty". Used alongside type, mostly on B2C and social touchpoints.

```jsx
<Icon name="burst" size="24px" />                 {/* small scale, next to type */}
<Icon name="rings" size="320px" scale="large" />  {/* enlarged graphic element */}
```

Names: `crossover`, `burst`, `zigzag`, `wave`, `sparkle`, `rings`, `star`, `cross`, `lines`, `orbit`.

Stroke is 1pt at small scale and 2pt at large scale, uniform across the whole icon. Never vary line widths within an icon, never distort proportions, never fill the shapes. Color: black, white, or the single sub-brand accent for the stroke.

This is a brand illustration set, not a UI glyph library. For functional UI affordances (chevrons, close, search) use a thin monochrome line icon (e.g. Lucide at 1–1.5px) and flag it as a substitution.
