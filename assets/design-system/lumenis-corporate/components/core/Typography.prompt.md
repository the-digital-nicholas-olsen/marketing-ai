Brand typography primitives. Titles are ALL CAPS Arizona Sans Regular, leading 88–92%, 0 tracking.

```jsx
{/* Option A — Hero L inside the message (1–2 words) */}
<Headline>Unvei<HeroL/> the best in you</Headline>

{/* Option B — Arizona Mix highlights 1–2 words */}
<Headline>Express your <Mix>inner beauty.</Mix></Headline>

<Subtitle>Lumenis is a global leader in minimally-invasive clinical solutions.</Subtitle>
<Caption>Captions and specs</Caption>
```

Rules: never mix Option A and Option B in one composition; never use the Hero L more than once per sentence; never set a whole headline in Arizona Mix; don't use Mix/HeroL with lowercase text; 4+ line headlines can stay all-Sans. Subtitles and paragraphs are sentence case.
