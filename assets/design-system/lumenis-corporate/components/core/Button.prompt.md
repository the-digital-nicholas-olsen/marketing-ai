Rectangular CTA button — square corners, Arizona Sans Regular, ALL CAPS, 0 tracking, leading 90–100%.

```jsx
<Button>Discover more</Button>
<Button variant="inverse">Discover more</Button>   {/* on a black ground */}
```

Variants: `primary` (black, the corporate default), `inverse` (white — use on black blocks), `outline`, `accent` (takes the single sub-brand color set by a parent `data-accent`; only when the content is about that sub-brand), `text` (underlined link). Sizes `s`/`m`/`l`.

Leave clear space around a CTA: the minimum gap between a headline and its button is one button height. Never round the corners, never use HubSpot orange.
