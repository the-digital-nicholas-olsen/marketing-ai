For a website or another published digital destination, confirm the applicable web-font rights and use the destination's authorized hosting method. For email, use the documented fallback stack because inboxes do not reliably load web fonts.

## Maintenance

Treat these as hosted delivery links, not proof that every use is approved. Before publication, confirm the asset is appropriate for the product, market, audience and output. If a HubSpot file is replaced or moved, use the employee's own authenticated HubSpot CLI account to locate the current file, verify the returned URL and update this index rather than uploading a duplicate.
