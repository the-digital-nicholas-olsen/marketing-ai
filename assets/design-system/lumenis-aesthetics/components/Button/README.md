The web button: a pill, the system's one rounded element, with an uppercase label.

**You provide.** The label as children; `href` for a link, or `onClick`; `kind`: `field` (default, the pairing's or product's field with its on-field type), `ink` (ink fill, white type), `outline` (ink outline on a light ground) or `text` (a plain link with an arrow in the field ink); `size: 'small'` in the header.

**Rules.** Web pages only; slides have no buttons. One `field` or `ink` button per group, the others `outline` or `text`. On a color block use `ink` first and `outline` second. Labels say what happens ("Request a seat", "See the agenda"). The plain-HTML classes are in [web.md](../../web.md).
