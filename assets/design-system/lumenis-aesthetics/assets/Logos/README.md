The official Lumenis wordmark and Hero L symbol, black and white SVG; the same files as Lumenis Corporate, copied so this system stands alone. Use them through the `Logo` component.

- `lumenis-wordmark-black.svg`: the footer wordmark on white, 89 wide on slides. Ink: black.
- `lumenis-wordmark-white.svg`: on the bookend block only, 210 wide on slides. Ink: white.
- `lumenis-hero-l-black.svg`, `lumenis-hero-l-white.svg`: the Hero L symbol. On color the symbol goes white.

Never on a photo, never recolored, outlined or redrawn.
