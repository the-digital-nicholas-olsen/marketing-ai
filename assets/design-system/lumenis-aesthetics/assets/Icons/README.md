The 10 approved Lumenis line icons: burst, cross, crossover, lines, orbit, rings, sparkle, star, wave, zigzag. Each is a 1-unit stroke in `currentColor`, so it takes the color of its text: use the `Icon` component and set `color`.

Black on white, white on color. Set them large, cropped by the edge of a color field, never touching type. No colored tile behind an icon on white; never altered, filled or recombined.
