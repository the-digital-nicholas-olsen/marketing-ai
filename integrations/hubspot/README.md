# HubSpot

How Lumenis marketing builds in HubSpot (portal 278427), for Vision and Aesthetics. Start with the skill for the asset you're making. Campaign skills such as Accelerate link here for the general method and keep only their own settings.

## Build an asset

| Making | Skill | What it covers |
|---|---|---|
| Landing page | [HubSpot landing page](../../.agents/skills/lumenis-hubspot-landing-page/SKILL.md) | One Custom HTML module written by the AI, editor sequence, template and CSS lessons, render checks |
| Marketing email | [HubSpot email](../../.agents/skills/lumenis-hubspot-email/SKILL.md) | One HTML body file, inline-CSS rules, every send setting set and read back, inbox QA |
| Form | [HubSpot form](../../.agents/skills/lumenis-hubspot-form/SKILL.md) | Division properties, hidden routing values, UTM fields, consent, embed and test submission |
| Email check | [Email check](../../.agents/skills/lumenis-email-check/SKILL.md) | Litmus previews, dark mode, mobile, links, images and send settings before scheduling |
| Campaign setup | [HubSpot campaign](../../.agents/skills/lumenis-hubspot-campaign/SKILL.md) | Campaign, ON24 registration and attendance segments, email shells and associations |
| Workflow | [HubSpot workflow](../../.agents/skills/lumenis-hubspot-workflow/SKILL.md) | Safety rules, Latest Lead Info first, recorded and proposed patterns, acceptance tests |
| Images | [Image library](../../assets/image-library/README.md) | Resize, upload to the file manager and verify links |

Webinar registration pages are built in ON24, not HubSpot.

## Shared references

- [Access and verification](access-and-verification.md): per-user CLI setup, account capabilities, read-back checklist and browser recovery.
- Division field mappings: [Vision](../../divisions/vision/hubspot/field-mappings.yaml) and [Aesthetics](../../divisions/aesthetics/hubspot/field-mappings.yaml).
- Campaigns and form-fill segments are still documented in the [Accelerate campaigns and segments reference](../../.agents/skills/lumenis-accelerate-campaign/references/campaigns-and-segments.md).

Drafting never authorizes publishing, sending or turning on a workflow. Keep object IDs, finished HTML and test results in the external campaign folder, not here.
